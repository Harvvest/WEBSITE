Access Control & Security Architecture

Server Auth Verification • Active
Every privileged request is verified cryptographically by the server using Supabase Auth. Client-provided roles or user IDs are never trusted.
UID Allowlist Check • Enforced
Only accounts with user IDs explicitly listed in the server-configured ADMIN_ALLOWED_UIDS environment variable can access this dashboard or admin endpoints.
Public Signup Restrictions • Blocked
Public user registration is disabled at the Supabase project level. Visitors cannot self-register or escalate privileges.
Row Level Security (RLS) • Schema Ready
Postgres RLS policies prepared in supabase-schema.sql. Unauthorized visitors cannot view drafts, private enquiries or alter data.
